# Publication notes

The third-party BugsInPy benchmark, checked-out upstream projects, datasets, local caches and run artifacts are not included. BugsInPy-related commands require a separately obtained benchmark and its applicable upstream licenses. Third-party packages are declared dependencies, not vendored library copies. No project license was found in the selected source.

This repository contains the selected research implementation and tests. The existing project describes later experiments as well as the initial work; it is not an assertion that every result in the research website has been independently reproduced from this subset.
